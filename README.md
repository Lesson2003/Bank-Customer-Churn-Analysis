## Project Overview

This project presents an interactive **Bank Customer Churn Analysis Dashboard developed using Microsoft Power BI** to analyse customer behaviour, identify churn patterns, and support customer retention strategies.

The dashboard transforms customer banking data into actionable insights by analysing demographics, financial indicators, product usage, and customer exit behaviour.

---

## Business Problem

Customer churn impacts banking profitability and customer lifetime value.

This dashboard answers:

- Which customers are leaving?
- What factors influence churn?
- Which customer segments are high risk?
- How can banks improve retention?

---

## Objectives

- Analyse customer churn patterns
- Identify customer retention opportunities
- Track banking KPIs
- Segment customers based on behaviour
- Support data-driven decisions
